## Живой Safari на Mac

Пользователь выбрал видео `BoPiM57aJSc` и разрешил проверить все три действия.
Начальное состояние — без голоса. Нативными нажатиями выполнено `1 → -1 → 0`.
После каждого действия в storage background проверен результат `delivered`,
пустая очередь и отсутствие ошибки. Этот статус записывается только после
буквального JSON `true` от `/interact/confirmVote`; HTTP 200 сам по себе не
считается доставкой. В Web Inspector также наблюдались POST `vote` и
`confirmVote`, оба HTTP 200. Тело ответа отдельно не экспортировалось.

| Действие | Значение | `lastDelivery.at` (Unix milliseconds) | Результат |
| --- | ---: | ---: | --- |
| Лайк | 1 | 1793614768868 | delivered, pending 0, failure null |
| Дизлайк | -1 | 1793614847753 | delivered, pending 0, failure null |
| Отмена | 0 | 1793614928728 | delivered, pending 0, failure null |

**Исходное отсутствие голоса восстановлено.** Случайный ID установки не
включён в отчёт. Подтверждён приём RYD; изменение публичного агрегированного
счётчика не является критерием этого теста.

На обычном видео в тёмной теме виден `≈ 25` внутри штатной кнопки, нижней панели
нет. Popup отображает последний подтверждённый голос. Выключатель проверен:
выключение → закрытие → повторное открытие сохраняет `off`; затем возвращён
`on`. Приложение macOS правильно показывает включённое расширение.

При отладке несколько сборок с одинаковым bundle ID были зарегистрированы
одновременно. После удаления дублирующих регистраций (без удаления файлов)
оставлена одна актуальная сборка из `/private/tmp/ryd-build-macos`. Ошибка
загрузки background и настроек popup исчезла. CSS popup также исправлен:
размер задаётся явно, без зависимости от `100vw`. При последующих сборках
Xcode может снова зарегистрировать другой экземпляр; проверять один экземпляр.

Попытка открыть `/shorts/` привела к `/watch?v=A80XBI_rnb0` в текущем профиле
Safari. Поэтому живую разметку Shorts этим проходом **не проверили**. В той
вкладке голоса не отправлялись; тестовая вкладка закрыта.

## iPhone и iPad

- На физический iPhone 17 Pro Max с iOS 27.2 установлена финальная подписанная
  сборка. Запуск через devicectl успешен; через iPhone Mirroring визуально
  проверен экран инструкций, английские тексты и отсутствие обрезания.
- До проверки Safari соединение Mirroring завершилось с сообщением
  `iPhone in Use`. Включение расширения и поведение мобильного Safari на этом
  устройстве пока не подтверждены.
- На iPad Pro 13-inch (M4), Simulator iPadOS 18.6 приложение установлено и
  запущено через simctl. Интерфейс Simulator недоступен текущему инструменту
  UI; визуальная проверка и Safari не засчитаны. Симулятор после проверки
  выключен. Физический iPad недоступен.
- macOS 13 и iOS/iPadOS 16 в доступной среде отсутствуют. Deployment target и
  успешная компиляция не заменяют запуск на минимальных ОС.

## Оставшийся релизный проход

Для каждой платформы (Mac, физические iPhone и iPad), включая минимальные
поддерживаемые ОС, требуется завершить следующую матрицу. Перед живым
голосованием записать исходное состояние и восстановить его после проверки.

| Сценарий | Mac | iPhone | iPad |
| --- | --- | --- | --- |
| Обычное видео, тёмная тема, реальная доставка 1/-1/0 | Пройден на текущей ОС | Осталось | Осталось |
| Обычное видео, светлая тема | Осталось | Осталось | Осталось |
| Shorts, обе темы, переход между роликами | Осталось: текущий профиль перенаправил на watch | Осталось | Осталось |
| Вход/выход, диалог входа без отправки голоса | Автотест; живой проход остался | Осталось | Осталось |
| SPA, замена кнопок, возврат назад | Автотест; полный живой проход остался | Осталось | Осталось |
| Потеря/возврат сети, очередь после выгрузки background | Автотест; живой проход остался | Осталось | Осталось |
| Фон/блокировка/возврат, alarm recovery | Автотест; живой проход остался | Осталось | Осталось |
| Popup и сохранение выключателя | Пройден | Осталось | Осталось |
| Минимальная поддерживаемая ОС | macOS 13 недоступна | iOS 16 недоступна | iPadOS 16 недоступна |

После завершения матрицы обновить этот документ фактическими устройствами,
версиями ОС и результатами. До этого не обозначать сборку как готовую к релизу.

сборке. Для этой правки требуется повторный визуальный проход на iPhone.
